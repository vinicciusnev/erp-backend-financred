# Projeto Fintech - API de Empréstimos

## Descrição
API RESTful para gestão de clientes e empréstimos usando Java 17 + Spring Boot + PostgreSQL + RabbitMQ.

## Tecnologias
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- RabbitMQ
- Lombok (opcional)

## Como rodar

### Pré-requisitos
- Java 17
- Docker e Docker Compose

docker-compose up -d
